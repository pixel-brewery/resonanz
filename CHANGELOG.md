# Changelog

## Unreleased — prototype 0.1.0

- Electron tray application with Angular, Mosaik and native icons.
- Explicit microphone recording, pause/resume, timestamps and durable local sessions.
- Keyless Codex/Claude integration through Synapse and native account sign-in.
- System recognition/output, spoken assistant turns, interruption and stereo archives.
- Session ring, measured waveforms, chapters, markers, structured evidence and questions.
- Weekly landscape and validated per-session topic threads, with a legacy shared-tag fallback.
- Reusable presentation components for timelines, evidence, input levels, reminders and confirmations.
- English/German translation tables, English default and independent speech settings.
- Owner-approved warm Soho palette and Georgia serif typography from the live Theme Editor export.
- Onboarding and native route-sized Settings/workspace/tray surfaces.
- Measured quiet-input reminders, persisted pause annotations and native speech pacing.
- Measured library storage, opt-in recording retention and confirmed library clearing.
- Favorites, tags, collections, local search and confirmed deletion.
- Audio/JSON imports and audio/JSON/Markdown exports.
- Unchanged upstream audio sources with reproducible provenance.
- macOS/Windows CI for native packaging and controlled application workflows.
- Public GitHub repository, MIT license and English documentation/contributor templates.
- Symphony-style window chrome: a unified toolbar that drags the window everywhere except its
  controls, back/forward navigation and per-screen titles and actions.
- Status bar with the running capture, a mini player for any playback, a notification bell
  with today's notices and bottom-left toasts instead of banners above the workspace.
- Installer updates checked from release manifests, downloaded with verified size and
  SHA-256, and installed on an explicit restart from the status bar or Settings.

This records working source behavior, not a published release tag, installer or update
channel. Actual runtime evidence and remaining requirements are recorded in
[verification](docs/project/verification.md).

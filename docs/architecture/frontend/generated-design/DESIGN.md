# Resonanz on Mosaik Soho

This is the light-mode projection of the owner-approved Resonanz theme. The
renderer applies the same source theme in both appearances through the public
Mosaik provider. The authored [interface foundations](../../../../DESIGN.md)
record Resonanz's interaction and visual decisions.

The generator reads the actual [Theme Editor export](../../../../resources/themes/resonanz-soho.ts)
and the pinned Soho model. [Component defaults](COMPONENTS.md) cover the model's
Mosaik vocabulary. The [configuration](../../../../tools/design-md.config.json)
owns the projection. Run `yarn design:md` to regenerate and `yarn design:md-check`
to compare the generated regions and validate their schema.

Apply its complete mandatory consumer workflow to every UI question, new idea and design decision; do not maintain a second procedure here. There is no hosted HTTP dependency or automatic web fallback. Follow [the local connection and compatibility contract](references/project.md#catalog-and-component-versions); report which source was actually consulted. This connection does not authorize recording, native account access, inference, cloud writes or publication.

From conversation to session

Record and mark

Record or import audio. Mark decisions, tasks and questions as you listen, then return to those moments directly.

Transcribe

Use your operating system’s speech recognition to create a transcript alongside the recording.

Ask and verify

Use Codex or Claude Code to summarize a session or answer questions. Follow the references back to the transcript and audio.

Set up your assistant

Install Codex or Claude Code and connect your account in Resonanz Settings. Recordings and session files stay on your device. When you request analysis, Resonanz sends the selected transcript context to your connected assistant.
